# Benchmark de recalage UAV

## Objectif

Comparer les matchers sur les mêmes données FireViewer sans promouvoir un modèle à partir de résultats externes.

## Candidats

- AerialExtreMatch-RoMa ;
- RoMa v2 ;
- AdHoP/OrthoLoC ;
- autres challengers enregistrés.

## Domaines séparés

- nadir ;
- oblique ;
- altitude faible ;
- altitude élevée ;
- rural ;
- montagne ;
- agricole ;
- fumée et occlusions ;
- variations saisonnières.

## Données

- groupes séparés par zone et séquence ;
- poses et intrinsics vérifiés ;
- lots critiques hors entraînement ;
- aucun incident actif.

## Mesures

- qualité des correspondances ;
- couverture ;
- pose ;
- erreurs critiques ;
- abstention ;
- stabilité ;
- temps et mémoire par profil.

## Promotion

Le rapport indique le domaine où un matcher est admis. Aucun matcher n’est déclaré universel.
